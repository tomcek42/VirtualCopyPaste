# S03: Mouse click detection via CGEventTap

**Goal:** Replace the placeholder sleep in the macOS type_text path with real mouse click detection using CGEventTap, so the app waits for the user to actually click (or double-click) in the target window before typing begins.
**Demo:** After Cmd+Tab, the app waits for the user to click (or double-click) in the target window. The click reaches the target app, then typing begins.

## Must-Haves

- wait_for_user_click_macos() detects left mouse button clicks via CGEventTap in listen-only mode, clicks pass through to the target app, timeout after 30s, placeholder sleep in type_text replaced. cargo check passes on Windows with no regressions.
