# S02: Core keyboard simulation via CGEvent

**Goal:** Implement macOS keyboard simulation using CGEvent APIs so that type_text works on macOS: Cmd+Tab switches windows, Unicode and Compatible (EN-US scancode) modes type characters correctly, and Enter/newlines work. Click detection is deferred to S03 — this slice uses a simple sleep placeholder on macOS.
**Demo:** User pastes text in the app, it Cmd+Tabs to the previous window, waits for a click, then types 'Hello World 123!\nLine 2' correctly into TextEdit. Both Standard (Unicode) and Compatible modes work.

## Must-Haves

- cargo check passes on Windows with no regressions. All new macOS functions compile behind #[cfg(target_os = "macos")]. The type_text command's macOS path calls cmd_tab, uses a sleep placeholder for click wait, then types characters using the selected keyboard mode.
