# S02: Core Paste Functionality (Character-by-Character)

**Goal:** Implement character-by-character paste into target windows via Rust backend keyboard simulation.
**Demo:** 

## Must-Haves

- Text entered in input is typed char-by-char into the target window after a configurable delay. Paste button triggers the operation. Status feedback shown in UI.

## Proof Level

- This slice proves: functional — text typed into target window character by character

## Integration Closure

Core paste feature end-to-end. Frontend button triggers Rust command that sends keystrokes.

## Verification

- Console logging of each keystroke sent. Status feedback in UI.
