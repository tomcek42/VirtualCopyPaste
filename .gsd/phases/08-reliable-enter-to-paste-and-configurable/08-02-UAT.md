## UAT: Configurable Paste Shortcut

Voraussetzung: `npm run tauri:dev` laeuft.

1. **Recorder aufnehmen** — Settings oeffnen -> 'Hotkey & Mouse' -> auf 'Paste Shortcut' klicken, `Strg+P` druecken. Erwartung: Feld zeigt `Ctrl+P`. Speichern.
2. **Live wirksam ohne Neustart** — Im Main-Window Text eingeben, `Strg+P` druecken. Erwartung: Paste-/Alt-Tab-Flow startet.
3. **Reines Enter pastet nicht mehr (bei Ctrl+P)** — Im Single-Line-Main-Window `Enter` druecken. Erwartung: kein Paste.
4. **Reset auf Enter** — Settings -> Reset-Button neben 'Paste Shortcut'. Erwartung: Feld zeigt `Enter`. Speichern. Im Main-Window `Enter` -> Paste startet.
5. **Multi-Line-Zeilenumbruch bleibt** — Input Mode auf Multi-line. Erwartung: reines `Enter` fuegt einen Zeilenumbruch ein; `Strg+Enter` pastet.

Automatisch bereits gruen: `node --check` (settings.js, app.js) und Node-Matcher-Harness (9/9 Faelle).
