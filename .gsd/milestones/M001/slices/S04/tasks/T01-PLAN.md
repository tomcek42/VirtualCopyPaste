# T01: Add multi-slot clipboard UI with 3 numbered slots

Add a slot selector UI with 3 numbered buttons (1, 2, 3) above the text input. Each slot stores independent text. Active slot is highlighted. Switching slots updates the text input to show that slot's content. Text input changes save to the active slot automatically. Style slots as compact numbered buttons in a row.

## Inputs

- `src/index.html`
- `src/styles.css`
- `src/app.js`

## Expected Output

- `src/index.html`
- `src/styles.css`
- `src/app.js`

## Verification

Click between slots — each stores independent text. Active slot highlighted.
